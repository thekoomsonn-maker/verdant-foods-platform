# Languages and translations

The language menu in the header switches the whole site. English is the source; every other language is a dictionary file in `src/lib/i18n/dicts/`:

| Language | File |
|---|---|
| Français | `fr.json` |
| Twi (Asante) | `tw.json` |
| Akuapem Twi | `ak.json` |
| Fante | `fat.json` |
| Ga | `gaa.json` |
| Ewe | `ee.json` |
| Dagbani | `dag.json` (marked "Soon" in the menu) |
| Gonja | `gjn.json` (marked "Soon" in the menu) |

Each file maps the exact English text to its translation:

```json
{ "Add to bag": "Fa to kotoku mu", "Paid within {#} hours": "Yɛtua wo ka wɔ nnɔnhwerew {#} mu" }
```

- `{#}` stands for any number on the page (prices, kilos, dates) and must stay in the translation.
- Anything missing from a file simply shows in English, so a file can be filled in step by step.
- To fix or add a translation, edit the file and redeploy. No code changes are needed.
- To leave a part of the page untranslated, add `data-i18n-skip` to its element.

How it works: `src/components/i18n/provider.tsx` translates the rendered page text, placeholders, labels and the tab title after each render, and remembers the English so switching languages is instant. Headlines that animate word by word translate the whole sentence first (`useT()`).

The Ghanaian-language files were should be reviewed by native speakers (field officers are ideal) before launch, especially longer paragraphs and food-safety wording.
