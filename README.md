# Verdant Foods Platform

Frontend for the Verdant Foods AgTech marketplace, traceability system and Digital VSLA platform.

- **Design source of truth:** Figma — *Verdant Foods — Platform* (Design Lab, Homepage, Marketplace, Farmer Dashboard)
- **Product docs:** [`/docs`](docs) — brief, architecture, design system, reference guide, and the Product Architecture & UX Plan PDF (v2.0)
- **Stack (from approved Figma):** Next.js · React · TypeScript · Tailwind · Vercel previews
- **Backend:** owned by Verdant's backend developer. The frontend runs on typed mock data until API docs are supplied — no API contracts are invented here.

Workflow: docs → Figma Design Lab → 3-screen checkpoint → review → module expansion → code.
